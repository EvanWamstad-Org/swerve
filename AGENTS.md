# Swerve project boundaries

Work only in EvanWamstad-Org/swerve. Never write to EvanWamstad-Org/Trio or modify its Apple app, identifiers, profiles or settings.
Preserve Swerve's separate bundle ID, extensions, App Group and private signing store. Never enable certificate revocation or use the original Trio identifiers for a Swerve build.

Use TrioDocs and actual source/workflow logs; record changes and verify before claiming a build works.
